# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.9.x   | :white_check_mark: |

## Report a Vulnerability

Please report security issues to **douglastalley@legacyai.space**.

We typically respond within 48 hours. Please do not open public GitHub issues for security vulnerabilities.

## Scope

This policy covers the Plumb PWA application and the Cloudflare Workers Trade Commons API (`workers/commons-api/`).

## Security Best Practices

When reporting vulnerabilities, please include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)
